2. Data and naming

Preferred MATLAB image variable: I. Use [Y X T] for a 2D acquisition and [Y X Z T] for step motor or 3D-like data. NIfTI input must be a 4D volume with a valid time dimension.

Use stable names that retain the animal and scan, for example RGRO_251119_1024_MM_B6_642_FUS_115354.mat and RGRO_260831_1024_MM_B6J_1336_scan4.mat. The loader stores sourceFile, animalId when detected, schemaVersion, tsec, and timeUnits for reproducibility.

2a. fUSI, TR, and resolution

Functional ultrasound imaging (fUSI) measures blood-volume or blood-flow-related changes with ultrafast ultrasound. A pixel or voxel is a spatial sample and the final dimension is time. Motion, probe pressure, vessels, physiology, anesthesia, and drift can all change the signal, so a bright map is not automatically neuronal activity.

TR is the interval between frames in seconds. The nominal sampling frequency is fs = 1/TR and the Nyquist frequency is fN = 1/(2*TR). The loader prefers physical timestamps when available; irregular timestamps should be resampled before filtering or frequency-domain FC. Spatial resolution is the physical pixel/voxel spacing and must agree across images, masks, underlays, registration, and atlas labels.

For voxel v, baseline-normalized percent signal change is PSC(v,t) = 100*(I(v,t)-B(v))/B(v), where B(v) is the finite positive mean of the selected baseline frames. Rebaselining uses PSCnew = 100*(PSCold-Bnew)/(100+Bnew). These are the equations used by SCM, ROI traces, and exports.

3. QC and preprocessing

Inspect frame outliers, frame rate, baseline coverage, and the raw movie before preprocessing. Frame interpolation only replaces explicitly rejected frames; it preserves the original 3D or 4D shape. Filtering uses the detected sampling interval, so verify timing when an acquisition is irregular.

Use scrubbing, motion correction, temporal smoothing, PCA, ICA, and despiking only when justified by the experiment. Save each output with a descriptive processing suffix and confirm that it appears in the active dataset list.

Frame rejection targets unusable whole frames; scrubbing detects high-change frames and interpolates them; despiking targets sparse voxel-wise outliers; Imregdemons corrects slow spatial deformation; drift compensation estimates a slow trend. Apply the least aggressive correction that resolves the QC finding, then re-run QC.

3a. Motion correction and Chop Data

Motion Correction opens one compact chooser for frame rejection, despiking, or scrubbing. Frame rejection targets whole-frame intensity excursions; despiking targets isolated voxel transients; scrubbing targets frame-to-frame changes. Each route keeps the acquisition timing and writes a derived dataset after QC.

Chop Data removes seconds from the start and/or end of the active recording. The cut dataset keeps the retained timestamps and original frame indices, resets its displayed time to zero, and is named with the requested start/end durations.

4. PSC, SCM, and ROI time courses

PSC is calculated as:

PSC = 100 * (signal - baseline) / baseline

Baseline samples must be finite and positive. In SCM GUI, change the baseline start/end fields and press Enter or leave the field. The map and ROI time course are recomputed from the selected window, and the exported percentage values use exactly the same rebasing formula:

PSC_new = 100 * (PSC_old - baseline_old) / (100 + baseline_old)

This prevents the common mismatch where export changes but the plotted trace still uses the original baseline.

Pinned ROIs, including ROIs added using typed coordinates, refresh with the baseline window. ROI traces give each finite voxel equal weight; missing voxels are excluded. Gaussian smoothing preserves invalid-baseline locations without spreading missing values into neighboring valid tissue.

5. PCA and ICA

The PCA/ICA window displays the active dataset, animal, and scan ID in its header. Computation uses temporal chunking and a compact temporal basis instead of making a full second copy of a large movie. ICA preserves the caller's random-number state. Review components in the viewer before removing them.

Unused component slots are blank. Apply & Close uses the green action color, while Cancel uses red. Cancel leaves the input movie unchanged.

7. Functional connectivity and group analysis

Individual FC reports finite-sample t statistics, valid sample counts, and FDR-adjusted q-values. Group motor data are aligned by subject identity and physical tsec before averaging; unequal frame grids are not combined by raw index. Confirm geometry, timing, group labels, and masks before interpreting group maps.

8. Memory, temporary saves, and exports

The loader selects the primary image variable and avoids loading duplicate large arrays. Chunked QC/PCA/ICA reduce peak working memory. The original image still determines the minimum memory requirement: the representative 3D scan can occupy several gigabytes. Close unused figures and process one dataset at a time when MATLAB reports memory pressure.

Large derived 3D files use a temporary MAT file and a cooperative save queue. Image chunks are appended while the GUI remains responsive; the final filename is published only after the staged file is complete. A queued or saving date label means the output is still being finalized.

Exports include source identity, schema version, timing, baseline window, valid counts, and processing metadata. Keep analysis folders separate from raw data and never overwrite raw acquisition files.

9. Help and troubleshooting

Every Help button opens context-specific guidance from docs/help_topics.json. Popups open maximized on the Studio monitor; if a panel is clipped, maximize the owning window. If a baseline is invalid, choose a window with finite positive signal. If timing is uncertain, inspect tsec and the loader report before filtering.
